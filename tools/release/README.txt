WoW AI 无限增强版 0.6.0-beta.1 · Windows x64 内测包

这是什么
基于 chelinho139/wow-ai 的社区修改版，包含 AI 聊天、任务区域路线、冒险日志与游记、副本任务与掉落提示。不是暴雪、OpenAI 或腾讯官方产品。
本包针对魔兽世界：无限 1.60 客户端（WowB.exe / Interface 16001）。未验证其他魔兽版本。

第一次安装
1. 把 ZIP 完整解压到普通文件夹，不要直接在压缩包里运行。
2. 完全退出游戏，并停止原有 WoW AI 桥接。
3. 双击 Install.cmd。选择包含 WowB.exe 和 Interface 的目录，通常是 _classic_beta_。
4. 选择你的游戏账号和默认 AI，点击“安装 / 升级”。账号列表为空时，先登录游戏一次并正常退出。
5. 点击“登录所选 AI”。首次会联网下载对应的官方命令行工具。随后在官方页面登录你自己的账号；不需要把密钥发给作者。
6. 点击“启动桥接”，重新启动游戏，确保 WoWAI 和 WoWAI_S 开头的通信插件启用。
7. 游戏里输入 /wow-ai 打开面板，发送“我在哪里”确认通信。进程启动成功不等于账号和游戏通信已验证。

日常使用
桌面快捷方式“WoW AI 无限”打开管理窗口，可启动/停止桥接、登录 AI、查看说明和冒险档案。
两种 AI 可以分别安装和登录，再在游戏面板上切换。桥接需要运行，Codex / WorkBuddy 桌面窗口不必一直打开。
选择 WorkBuddy 时使用官方 CodeBuddy Code 执行引擎和系统模型 auto，需要独立完成中国站登录，不直接控制 WorkBuddy 桌面任务，也不复用作者的自定义 API。
每位用户使用自己的 AI 账号与额度，订阅和可用模型由服务商决定。不同产品的账号/订阅权益不保证互通。
本版不会自动启动桥接或随 Windows 开机运行。

游戏窗口与通信
推荐“全屏（窗口）”/无边框窗口。独占全屏未支持；最小化或遮挡游戏可能中断画面采集。
发送聊天、规划、同步日志时出现的彩条是游戏到桥接的数据通道，请不要遮住它。
首次安装新增大量通信文件，必须完全退出并重启游戏，仅 /reload 不够。

功能提示
任务助手：点击 AI 规划路线处理当前任务；当前地图任务区域显示数字顺序，按实际任务进度推进。副本任务不混入野外路线。自动更新与手动规划分别控制。
冒险日志：上线自动记录，从上线地点开始；按天翻页，记录任务、击杀、拾取等。正常退出或 /reload 会保存游戏内数据；同步新增日志后会在电脑档案中保留副本。异常崩溃前尚未保存、未同步的数据仍可能丢失。
生成游记：基于已有记录生成文字，长记录分批处理；可重试。旧记录缺少地点时不会编造起点。
副本助手：按阵营和任务条件显示任务；可在副本外检查。掉落图标和当前天赋比较仅为参考，资料覆盖仍不完整。
清除 AI 标记：使用界面顶部对应按钮。

你的数据与隐私
安装位置：%LOCALAPPDATA%\WoWAI-Forever
冒险档案：安装目录\data\workspace\adventure-log（管理窗口可直接打开）
聊天与桥接状态：安装目录\app\bridge
WorkBuddy 登录缓存：安装目录\data\workbuddy-auth；Codex 登录由官方 CLI 管理。
聊天会向所选 AI 服务发送输入内容和角色/任务/位置等游戏上下文；规划会发送任务信息，生成游记会发送冒险素材。
默认 AI 权限限制为查询用途。不要把私人文件放进冒险工作目录。
分享错误时请先检查日志，不要上传整个安装目录、WTF 文件夹、登录缓存、聊天或冒险档案。
发布 ZIP 不包含作者的 AI 登录、API 密钥、游戏账号、聊天、冒险记录或本机配置。

升级与迁移
关闭游戏和桥接后运行新版安装包。由本安装器安装的版本会保留配置、聊天、AI 登录和冒险档案。
旧插件目录及配置会先备份到安装目录\backups；游戏 WTF 存档不会删除。
以前手动安装的桥接和电脑冒险档案不会自动迁移到新安装目录，请先另行备份。新旧桥接不能同时连接同一套 WoWAI。
安装中断时不要启动游戏，排除权限/空间问题后重试；若需还原插件，可从备份中的 WoWAI 目录恢复。安装程序不是事务式全盘回滚工具。
若安装器提示没有写入权限，请调整游戏 AddOns 目录的写入权限；不要将整个游戏目录或账号文件发给他人。

卸载
停止桥接并退出游戏。先备份冒险档案。可删除 AddOns 中的 WoWAI 和 WoWAI_S001 到 WoWAI_S200，以及桌面快捷方式。
安装目录包含你的记录和登录缓存；确认备份后再手动删除。不要误删其他插件或整个 WTF。

内测已知限制
本包完成自动化代码/安装流程验证，但尚未在一台全新玩家电脑上完成登录与游戏内全流程验收。
还需实测：首次安装、两种 AI 登录和来回对话、路线数字标记、正常下线后日志、跨天翻页、游记生成以及升级保留数据。
网络下载失败或官方登录失败时，可再次点击对应登录按钮重试。WorkBuddy 桌面能聊天不代表 CodeBuddy 引擎账号已登录或有相同权限。
