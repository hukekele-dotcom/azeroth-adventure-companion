艾澤拉斯冒險夥伴 · 安裝與使用說明
適用版本：0.6.0-beta.9（Windows x64 內測版）

第一次使用：完整解壓縮 → 安裝 → 登入 AI → 啟動橋接 → 重啟遊戲 → /wow-ai
以後使用：桌面“WoW AI 无限” → 啟動橋接 → 進入遊戲。

本說明包含安裝、AI 登入、日常使用、疑難排解、備份和解除安裝。開啟 README.html 可選擇簡體中文、繁體中文或英文，三份說明均可離線檢視。安裝程式和桌面管理視窗目前使用中文按鈕，英文說明附有中文按鈕名。遊戲內語言單獨設定，選擇說明語言不會修改遊戲語言。

一、安裝前準備

本包用於《魔獸世界：無限》1.60 客戶端，遊戲目錄中應有 WowB.exe。未驗證其他魔獸版本，不適用於 macOS。

請準備：
• 已安裝的無限客戶端；不必先登入遊戲，也不必選擇遊戲帳號。
• 可用網路和你自己的 AI 帳號。Codex、WorkBuddy 可以先選一種，另一種以後再配置。
• 完整的 WoWAI-Forever-0.6.0-beta.9-win-x64.zip。

執行環境已隨包提供，不需要自己安裝 Node.js。AI 工具在首次登入時連網下載，每位玩家使用自己的帳號與額度，本包不附贈 AI 帳號或額度。
「橋接」是電腦後臺連線遊戲插件和 AI 的程式。遊戲裡的插件和電腦上的橋接需要配合執行。

是否要先安裝 Codex 或 WorkBuddy？
• 使用 AI 聊天、AI 路線規劃和生成遊記，至少要安裝並登入一種 AI 執行元件；不需要兩種都裝。
• 使用本 Windows 安裝包時，不必預先安裝 Codex 或 WorkBuddy 桌面應用程式。先完成“1. 安装 / 升级”，再點選“2. 登录所选 AI”，程式會連網下載並安裝所選 AI 的官方執行元件，然後引導登入。
• 選擇 Codex：安裝 Codex CLI，依提示登入你自己的帳號。選擇 WorkBuddy：安裝官方 CodeBuddy Code 執行元件，並單獨完成中國站帳號登入。
• 已在桌面應用程式登入，也要依本安裝包的登入流程確認；WorkBuddy 桌面登入不會自動取代執行元件登入。
• 想在遊戲內切換兩種 AI，需要分別點選“登录 Codex”和“登录 WorkBuddy”，完成兩邊的安裝和登入。
• 日常使用須啟動本插件的橋接後臺；無需一直開啟 Codex / WorkBuddy 桌面視窗。首次元件下載需要網路，AI 請求也需要網路和所選服務的可用帳號額度。
• 顯示“安裝完成”只表示插件已安裝，不代表 AI 已準備好；依第 6 步完成兩則遊戲內訊息測試後再使用 AI 功能。

二、首次安裝：按順序完成六步

第 1 步：完整解壓縮

把 ZIP 解壓到普通資料夾。開啟後應能看到 Install.cmd、README.html、三份 Install-Guide-*.txt、runtime 和 app 等檔案或資料夾。
不要在壓縮軟體裡直接執行，也不要只複製 Install.cmd 一個檔案。請下載發布頁中具名的 Windows 安裝包，GitHub 自動生成的 Source code 是開發原始碼，不是玩家安裝包。

第 2 步：退出遊戲和舊橋接

完全退出遊戲。如果已經安裝過本工具，請在桌面“WoW AI 无限”中點選“停止桥接”。舊手動安裝版也要先停止後臺橋接。
不要讓新舊橋接同時連線同一套 WoWAI 插件。

第 3 步：選擇目錄和 AI

雙擊 Install.cmd，在安裝視窗中：
① 點選“选择目录”，選擇直接包含 WowB.exe 和 Interface 資料夾的目錄，通常是 _classic_beta_。
   例如遊戲裝在 D:\Games\World of Warcraft，應選 D:\Games\World of Warcraft\_classic_beta_。
   不要選擇外層啟動器目錄，也不要選擇 Interface\AddOns。
② 無需選擇遊戲帳號。後臺自動讀取此客戶端各帳號的 WoWAI 存檔；首次遊戲結束或 /reload 後會自動發現新存檔。
③ 在“默认 AI”中選擇 Codex 或 WorkBuddy。遊戲內也能切換，但兩種 AI 要分別完成登入。

帳號資料夾尚未生成也可以安裝；遊戲帳號與 AI 登入帳號是兩回事。
點選“说明 / 說明 / Help”可以開啟離線語言選擇頁。

第 4 步：安裝檔案

點選“1. 安装 / 升级”，等待提示安裝完成。
安裝程式會複製插件、生成通訊檔案，並建立桌面捷徑“WoW AI 无限”。程式預設安裝到：
%LOCALAPPDATA%\WoWAI-Forever

第 5 步：登入所選 AI

點選“2. 登录所选 AI”。首次會開啟命令提示字元視窗下載官方 AI 工具，然後進入登入流程。下載期間請保持網路連線。

選擇 Codex：
• 按命令提示字元視窗和官方登入頁面提示，登入自己的帳號。
• 登入結束後返回命令提示字元視窗，按提示關閉視窗。

選擇 WorkBuddy：
• 此入口使用官方 CodeBuddy Code 執行引擎，看到 CodeBuddy 名稱是正常的。
• 按提示選擇中國站並登入自己的帳號。若進入互動介面但尚未登入，可輸入 /login。
• 登入完成後，可輸入 /exit 離開互動介面，再按提示關閉視窗。
• 插件選擇系統模型 auto，不使用作者配置的自訂 API。
• WorkBuddy 桌面端已登入，不代表這個執行引擎已登入，也不能保證兩者帳號權益完全一致。

本安裝流程不要求填寫作者的 API 金鑰。登入視窗退出不代表 AI 通訊已成功，還需要下一步測試。

第 6 步：啟動橋接並測試

① 點選“3. 启动桥接”。以後也可從桌面“WoW AI 无限”點選“启动桥接”。
② 重新啟動遊戲，在插件列表中確認 WoWAI 和 WoWAI_S 開頭的通訊插件已啟用。首次安裝必須完全重啟遊戲，僅 /reload 不夠。
③ 推薦使用“全屏（窗口）”或無邊框視窗。當前不支援獨佔全屏；最小化或遮擋遊戲可能影響通訊。
④ 進入角色後，在聊天框輸入 /wow-ai 打開面板。
⑤ 在“AI 聊天”中選擇已經登入的 AI，傳送“我在哪里”，再發送一條後續訊息。

連續收到與當前角色資訊相符的回覆，才算完成首次通訊測試。“桥接已启动”只說明後臺程序在執行。

三、以後每天怎麼用

1. 雙擊桌面“WoW AI 无限”，點選“启动桥接”。
2. 進入遊戲，輸入 /wow-ai 打開面板。
3. 正常使用聊天、任務助手、冒險日誌和副本助手。
4. 遊戲結束時正常退出；不用 AI 時，可從桌面管理視窗點選“停止桥接”。

通常不用每天重新登入 AI；出現認證失效時再登入。橋接需要執行，Codex / WorkBuddy 桌面聊天視窗不必一直開啟。本版不會自動隨 Windows 開機啟動。

配置另一種 AI：停止橋接 → 點選“登录 Codex”或“登录 WorkBuddy” → 完成登入 → 重新啟動橋接 → 在遊戲面板切換 AI。

安裝後，在桌面管理視窗點選“说明 / 說明 / Help”，即可選擇語言並重新檢視完整說明。

四、主要功能怎麼用

任務助手
“AI 规划路线”處理當下任務，與“自动更新”分別控制。路線按當前地圖的任務區域顯示數字順序，根據實際任務進度推進；副本任務不混入野外路線。箭頭提供方向，不會自動替你移動或完成任務。
不需要標記時，點選介面頂部“清除 AI 标记”。

冒險日誌與遊記
上線自動記錄，按天檢視旅程，包含任務、擊殺和拾取等，沒有完整戰鬥明細。能取得上線地點時，旅程從該地點開始；舊記錄缺失地點時不會編造。
“同步新增日志”只傳尚未確認同步的記錄。“生成游记”將記錄整理成文字，長記錄分批處理。
從桌面管理視窗點選“查看冒险档案”，可以開啟電腦中的檔案。正常退出或 /reload 會儲存遊戲內記錄；同步後電腦端另有檔案。崩潰前尚未儲存、未同步的記錄仍可能丟失。

副本助手
可在副本外檢查任務接取情況，按陣營及任務條件顯示任務，並檢視首領掉落圖示和當前天賦、裝備的比較提示。資料覆蓋仍不完整，不能保證包含全部任務和掉落。

任務詳情顯示最低接取等級，等級不足時提示還差幾級；頂部依目前角色的陣營、職業與剩餘已收錄任務，提供集中清任務的等級參考。前置鏈、副本內接取與資料缺漏會另外說明。此等級不是戰鬥等級建議，也不保證一趟完成全部任務。

五、常見問題

雙擊後沒有安裝視窗
確認已完整解壓縮，Install.cmd、Install.ps1 和 runtime 在同一資料夾。若 Windows 阻止執行，請保留具體提示反饋，不要關閉全域性安全保護來嘗試。

提示目錄錯誤
選包含 WowB.exe 和 Interface 的那一層目錄，通常是 _classic_beta_。無需選擇遊戲帳號。

提示退出遊戲或停止橋接
完全退出遊戲，停止舊版和本版橋接再重試。關閉遊戲裡的插件面板不等於停止電腦後臺橋接。

提示拒絕訪問、沒有寫入許可權
檢查當前 Windows 使用者是否可以寫入遊戲目錄中的 Interface\AddOns。不要為此刪除 WTF、其他插件或整個遊戲目錄。

AI 工具下載失敗
檢查網路，停止橋接後重新點選對應“登录”按鈕。仍失敗時，記錄命令提示字元視窗中的錯誤文字；不需要重灌遊戲。

WorkBuddy 報 Authentication required、尚未完成認證
停止橋接，點選“登录 WorkBuddy”，在官方 CodeBuddy 執行引擎中重新完成中國站登入，然後啟動橋接並在遊戲中測試。僅開啟 WorkBuddy 桌面端不能解決獨立登入問題。

報 exited with code 0 and no result，或其他橋接錯誤
記下所選 AI、時間和完整錯誤提示。從桌面管理視窗點選“打开桥接日志目录”，檢視 bridge.log、startup.log、startup-error.log。反饋必要片段，不要傳送整份帳號目錄或登入快取。

/wow-ai 沒反應，或插件不在列表裡
確認安裝時選中了正在執行的客戶端，檢查插件是否啟用，再完全退出並重啟遊戲。

橋接已啟動，但訊息沒有回覆
確認遊戲裡選擇的 AI 已經登入，使用全屏（視窗）模式並保持遊戲可見，再檢視“安装状态检查”和橋接日誌。狀態檢查只檢查本機檔案和程序，不能代替帳號認證與遊戲內對話測試。

左上角出現彩條，像破圖
聊天、規劃或同步時，彩條用於遊戲向橋接傳送資料，請不要遮擋它。

找不到冒險檔案
先在遊戲裡完成“同步新增日志”，再點選桌面管理視窗的“查看冒险档案”。尚未同步時，電腦端可能還沒有這個角色的檔案。

說明頁面打不開或沒有瀏覽器
用記事本開啟 Install-Guide-zhCN.txt；繁體和英文分別是 Install-Guide-zhTW.txt、Install-Guide-en.txt，無需連網。請保留完整解壓縮資料夾，以免網頁中的本地連結失效。

六、更新、備份和解除安裝

更新：退出遊戲、停止橋接，解壓新版包並執行 Install.cmd。本安裝程式安裝的版本會保留配置、聊天、登入快取和冒險檔案；舊插件和配置會備份到安裝目錄的 backups 資料夾。
以前手動安裝版的電腦檔案不會自動遷移，請先單獨備份。遊戲 WTF 存檔不會被安裝程式刪除。
安裝中斷時不要啟動遊戲，排除提示中的許可權或磁碟空間問題後重試。需要時可從備份的 WoWAI 資料夾恢復舊插件；安裝程式不提供整個安裝目錄的事務式回滾。

備份：正常退出遊戲後，備份電腦端冒險檔案及對應帳號中的 WoWAI 遊戲存檔。不要把正在使用的程式目錄重新打包給別人，其中可能含登入和私人記錄。

解除安裝：停止橋接、退出遊戲並備份資料後，可刪除 AddOns 中的 WoWAI 和 WoWAI_S001 至 WoWAI_S200，以及桌面捷徑。確認檔案已備份後，再手動刪除程式安裝目錄。不要誤刪其他插件或整個 WTF。

預設路徑（可複製到資源管理器位址列）：
• 程式：%LOCALAPPDATA%\WoWAI-Forever
• 冒險檔案：%LOCALAPPDATA%\WoWAI-Forever\data\workspace\adventure-log
• 橋接日誌和聊天狀態：%LOCALAPPDATA%\WoWAI-Forever\app\bridge
• WorkBuddy 登入快取：%LOCALAPPDATA%\WoWAI-Forever\data\workbuddy-auth
Codex 登入由官方 CLI 管理。

七、內測反饋、隱私與來源

反饋問題時，請提供插件版本、客戶端版本、所選 AI、操作步驟、發生時間、錯誤文字或截圖。截圖遮住不想公開的角色和聊天內容，不要傳送密碼、驗證碼、API 金鑰或登入快取。

本版已完成自動化程式碼與安裝檢查，仍需在其他電腦驗證真實帳號登入和遊戲內全流程，請按內測版使用和分發。
聊天會把輸入與角色上下文傳送給所選 AI；規劃會發送任務資訊，生成遊記會發送冒險素材。每位玩家使用自己的帳號和額度。

預設 AI 許可權用於查詢，不要把私人檔案放進冒險工作目錄。發布包不含作者帳號、登入、配置、聊天或冒險記錄。
