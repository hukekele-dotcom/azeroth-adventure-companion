艾泽拉斯冒险伙伴 · 安装与使用说明
适用版本：0.6.0-beta.4（Windows x64 内测版）

第一次使用：完整解压 → 安装 → 登录 AI → 启动桥接 → 重启游戏 → /wow-ai
以后使用：桌面“WoW AI 无限” → 启动桥接 → 进入游戏。

本说明包含安装、AI 登录、日常使用、故障排查、备份和卸载。打开 README.html 可选择简体中文、繁体中文或英文，三份说明均可离线查看。安装器和桌面管理窗口目前使用中文按钮，英文说明附有中文按钮名。游戏内语言单独设置，选择说明语言不会修改游戏语言。

一、安装前准备

本包用于《魔兽世界：无限》1.60 客户端，游戏目录中应有 WowB.exe。未验证其他魔兽版本，不适用于 macOS。

请准备：
• 已安装的游戏，并至少登录过一次、正常退出，让游戏生成账号目录。
• 可用网络和你自己的 AI 账号。Codex、WorkBuddy 可以先选一种，另一种以后再配置。
• 完整的 WoWAI-Forever-0.6.0-beta.4-win-x64.zip。

运行环境已随包提供，不需要自己安装 Node.js。AI 工具在首次登录时联网下载，每位玩家使用自己的账号与额度，本包不附赠 AI 账号或额度。
“桥接”是电脑后台连接游戏插件和 AI 的程序。游戏里的插件和电脑上的桥接需要配合运行。

是否要先安装 Codex 或 WorkBuddy？
• 使用 AI 聊天、AI 路线规划和生成游记，至少要安装并登录一种 AI 运行组件；不需要两种都装。
• 使用本 Windows 安装包时，不必预先安装 Codex 或 WorkBuddy 桌面客户端。先完成“1. 安装 / 升级”，再点击“2. 登录所选 AI”，程序会联网下载并安装所选 AI 的官方运行组件，然后引导登录。
• 选择 Codex：安装 Codex CLI，按提示登录你自己的账号。选择 WorkBuddy：安装官方 CodeBuddy Code 执行组件，并单独完成中国站账号登录。
• 已在桌面客户端登录，也要按本安装包的登录流程确认；WorkBuddy 桌面登录不会自动替代执行组件登录。
• 想在游戏内切换两种 AI，需要分别点击“登录 Codex”和“登录 WorkBuddy”，完成两边的安装和登录。
• 日常使用须启动本插件的桥接后台；无需一直打开 Codex / WorkBuddy 桌面窗口。首次组件下载需要网络，AI 请求也需要网络和所选服务的可用账号额度。
• 显示“安装完成”只表示插件已安装，不代表 AI 已准备好；按第 6 步完成两条游戏内消息测试后再使用 AI 功能。

二、首次安装：按顺序完成六步

第 1 步：完整解压

把 ZIP 解压到普通文件夹。打开后应能看到 Install.cmd、README.html、三份 Install-Guide-*.txt、runtime 和 app 等文件或文件夹。
不要在压缩软件里直接运行，也不要只复制 Install.cmd 一个文件。请下载发布页中具名的 Windows 安装包，GitHub 自动生成的 Source code 是开发源码，不是玩家安装包。

第 2 步：退出游戏和旧桥接

完全退出游戏。如果已经安装过本工具，请在桌面“WoW AI 无限”中点击“停止桥接”。旧手动安装版也要先停止后台桥接。
不要让新旧桥接同时连接同一套 WoWAI 插件。

第 3 步：选择目录、账号和 AI

双击 Install.cmd，在安装窗口中：
① 点击“选择目录”，选择直接包含 WowB.exe 和 Interface 文件夹的目录，通常是 _classic_beta_。
   例如游戏装在 D:\Games\World of Warcraft，应选 D:\Games\World of Warcraft\_classic_beta_。
   不要选择外层启动器目录，也不要选择 Interface\AddOns。
② 在“游戏账号”中选择准备使用的账号。这里显示的是游戏生成的账号目录，不是角色列表。多个账号时要明确选择。
③ 在“默认 AI”中选择 Codex 或 WorkBuddy。游戏内也能切换，但两种 AI 要分别完成登录。

账号列表为空：先在这套客户端登录一次游戏并正常退出，再重新选择目录。
点击“说明 / 說明 / Help”可以打开离线语言选择页。

第 4 步：安装文件

点击“1. 安装 / 升级”，等待提示安装完成。
安装器会复制插件、生成通信文件，并创建桌面快捷方式“WoW AI 无限”。程序默认安装到：
%LOCALAPPDATA%\WoWAI-Forever

第 5 步：登录所选 AI

点击“2. 登录所选 AI”。首次会打开命令窗口下载官方 AI 工具，然后进入登录流程。下载期间请保持网络连接。

选择 Codex：
• 按命令窗口和官方登录页面提示，登录自己的账号。
• 登录结束后返回命令窗口，按提示关闭窗口。

选择 WorkBuddy：
• 此入口使用官方 CodeBuddy Code 执行引擎，看到 CodeBuddy 名称是正常的。
• 按提示选择中国站并登录自己的账号。若进入交互界面但尚未登录，可输入 /login。
• 登录完成后，可输入 /exit 离开交互界面，再按提示关闭窗口。
• 插件选择系统模型 auto，不使用作者配置的自定义 API。
• WorkBuddy 桌面端已登录，不代表这个执行引擎已登录，也不能保证两者账号权益完全一致。

本安装流程不要求填写作者的 API 密钥。登录窗口退出不代表 AI 通信已成功，还需要下一步测试。

第 6 步：启动桥接并测试

① 点击“3. 启动桥接”。以后也可从桌面“WoW AI 无限”点击“启动桥接”。
② 重新启动游戏，在插件列表中确认 WoWAI 和 WoWAI_S 开头的通信插件已启用。首次安装必须完全重启游戏，仅 /reload 不够。
③ 推荐使用“全屏（窗口）”或无边框窗口。当前不支持独占全屏；最小化或遮挡游戏可能影响通信。
④ 进入角色后，在聊天框输入 /wow-ai 打开面板。
⑤ 在“AI 聊天”中选择已经登录的 AI，发送“我在哪里”，再发送一条后续消息。

连续收到与当前角色信息相符的回复，才算完成首次通信测试。“桥接已启动”只说明后台进程在运行。

三、以后每天怎么用

1. 双击桌面“WoW AI 无限”，点击“启动桥接”。
2. 进入游戏，输入 /wow-ai 打开面板。
3. 正常使用聊天、任务助手、冒险日志和副本助手。
4. 游戏结束时正常退出；不用 AI 时，可从桌面管理窗口点击“停止桥接”。

通常不用每天重新登录 AI；出现认证失效时再登录。桥接需要运行，Codex / WorkBuddy 桌面聊天窗口不必一直打开。本版不会自动随 Windows 开机启动。

配置另一种 AI：停止桥接 → 点击“登录 Codex”或“登录 WorkBuddy” → 完成登录 → 重新启动桥接 → 在游戏面板切换 AI。

安装后，在桌面管理窗口点击“说明 / 說明 / Help”，即可选择语言并重新查看完整说明。

四、主要功能怎么用

任务助手
“AI 规划路线”处理当下任务，与“自动更新”分别控制。路线按当前地图的任务区域显示数字顺序，根据实际任务进度推进；副本任务不混入野外路线。箭头提供方向，不会自动替你移动或完成任务。
不需要标记时，点击界面顶部“清除 AI 标记”。

冒险日志与游记
上线自动记录，按天查看旅程，包含任务、击杀和拾取等，没有完整战斗明细。能取得上线地点时，旅程从该地点开始；旧记录缺失地点时不会编造。
“同步新增日志”只传尚未确认同步的记录。“生成游记”将记录整理成文字，长记录分批处理。
从桌面管理窗口点击“查看冒险档案”，可以打开电脑中的档案。正常退出或 /reload 会保存游戏内记录；同步后电脑端另有档案。崩溃前尚未保存、未同步的记录仍可能丢失。

副本助手
可在副本外检查任务接取情况，按阵营及任务条件显示任务，并查看首领掉落图标和当前天赋、装备的比较提示。资料覆盖仍不完整，不能保证包含全部任务和掉落。

任务详情显示最低接取等级，等级不足时提示还差几级；顶部按当前角色的阵营、职业及剩余已收录任务给出集中清任务的等级参考。前置链、本内接取和资料缺失会另外说明。这个等级不是战斗等级建议，也不保证一趟做完全部任务。

五、常见问题

双击后没有安装窗口
确认已完整解压，Install.cmd、Install.ps1 和 runtime 在同一文件夹。若 Windows 阻止运行，请保留具体提示反馈，不要关闭全局安全保护来尝试。

提示目录错误或没有账号
选包含 WowB.exe 和 Interface 的那一层目录，通常是 _classic_beta_。账号列表为空时，先在这套客户端登录一次并正常退出，再重新选择目录。

提示退出游戏或停止桥接
完全退出游戏，停止旧版和本版桥接再重试。关闭游戏里的插件面板不等于停止电脑后台桥接。

提示拒绝访问、没有写入权限
检查当前 Windows 用户是否可以写入游戏目录中的 Interface\AddOns。不要为此删除 WTF、其他插件或整个游戏目录。

AI 工具下载失败
检查网络，停止桥接后重新点击对应“登录”按钮。仍失败时，记录命令窗口中的错误文字；不需要重装游戏。

WorkBuddy 报 Authentication required、尚未完成认证
停止桥接，点击“登录 WorkBuddy”，在官方 CodeBuddy 执行引擎中重新完成中国站登录，然后启动桥接并在游戏中测试。仅打开 WorkBuddy 桌面端不能解决独立登录问题。

报 exited with code 0 and no result，或其他桥接错误
记下所选 AI、时间和完整错误提示。从桌面管理窗口点击“打开桥接日志目录”，查看 bridge.log、startup.log、startup-error.log。反馈必要片段，不要发送整份账号目录或登录缓存。

/wow-ai 没反应，或插件不在列表里
确认安装时选中了正在运行的客户端，检查插件是否启用，再完全退出并重启游戏。

桥接已启动，但消息没有回复
确认游戏里选择的 AI 已经登录，使用全屏（窗口）模式并保持游戏可见，再查看“安装状态检查”和桥接日志。状态检查只检查本机文件和进程，不能代替账号认证与游戏内对话测试。

左上角出现彩条，像花屏
聊天、规划或同步时，彩条用于游戏向桥接传送数据，请不要遮挡它。

找不到冒险档案
先在游戏里完成“同步新增日志”，再点击桌面管理窗口的“查看冒险档案”。尚未同步时，电脑端可能还没有这个角色的档案。

说明页面打不开或没有浏览器
用记事本打开 Install-Guide-zhCN.txt；繁体和英文分别是 Install-Guide-zhTW.txt、Install-Guide-en.txt，无需联网。请保留完整解压文件夹，以免网页中的本地链接失效。

六、更新、备份和卸载

更新：退出游戏、停止桥接，解压新版包并运行 Install.cmd。本安装器安装的版本会保留配置、聊天、登录缓存和冒险档案；旧插件和配置会备份到安装目录的 backups 文件夹。
以前手动安装版的电脑档案不会自动迁移，请先单独备份。游戏 WTF 存档不会被安装器删除。
安装中断时不要启动游戏，排除提示中的权限或磁盘空间问题后重试。需要时可从备份的 WoWAI 文件夹恢复旧插件；安装器不提供整个安装目录的事务式回滚。

备份：正常退出游戏后，备份电脑端冒险档案及对应账号中的 WoWAI 游戏存档。不要把正在使用的程序目录重新打包给别人，其中可能含登录和私人记录。

卸载：停止桥接、退出游戏并备份资料后，可删除 AddOns 中的 WoWAI 和 WoWAI_S001 至 WoWAI_S200，以及桌面快捷方式。确认档案已备份后，再手动删除程序安装目录。不要误删其他插件或整个 WTF。

默认路径（可复制到资源管理器地址栏）：
• 程序：%LOCALAPPDATA%\WoWAI-Forever
• 冒险档案：%LOCALAPPDATA%\WoWAI-Forever\data\workspace\adventure-log
• 桥接日志和聊天状态：%LOCALAPPDATA%\WoWAI-Forever\app\bridge
• WorkBuddy 登录缓存：%LOCALAPPDATA%\WoWAI-Forever\data\workbuddy-auth
Codex 登录由官方 CLI 管理。

七、内测反馈、隐私与来源

反馈问题时，请提供插件版本、客户端版本、所选 AI、操作步骤、发生时间、错误文字或截图。截图遮住不想公开的角色和聊天内容，不要发送密码、验证码、API 密钥或登录缓存。

本版已完成自动化代码与安装检查，仍需在其他电脑验证真实账号登录和游戏内全流程，请按内测版使用和分发。
聊天会把输入与角色上下文发送给所选 AI；规划会发送任务信息，生成游记会发送冒险素材。每位玩家使用自己的账号和额度。

默认 AI 权限用于查询，不要把私人文件放进冒险工作目录。发布包不含作者账号、登录、配置、聊天或冒险记录。
